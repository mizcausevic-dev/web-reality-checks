What was run, and what it does not prove

Central idea. Two pages can look identical after JavaScript runs while their initial HTTP responses contain different amounts of meaningful content; the initial HTML and the eventual DOM are different artefacts.

What this fixture is

  • fixtures/ep19-initial-html/ — one synthetic article (article.json, a fictional harbour tide clock) statically generated by build.mjs into two variants: CSR (/csr/article/: an application shell plus /csr/app.js, which fetches /article.json and inserts the article) and SSG (/ssg/article/: the article in the HTML, no script).
  • Both variants share <title>, <meta name="description">, <meta name="robots">, heading structure, ordinary <a href> links and article text, and are built from the same renderArticle() function; only when the article enters the document differs.
  • server.mjs — loopback static server, exact paths only, 301 to the trailing-slash form, explicit 404 for every missing route, no SPA fallback (a dev server's "index.html for everything" would hide route errors behind a 200 shell).
  • inspect.mjs — raw HTTP fetch of both routes (captures/raw-*.html) and rendered-DOM capture via the Remotion-bundled headless Chrome driven over the DevTools protocol, with JavaScript enabled and disabled in a fresh profile (captures/dom-*.html, inspection-results.json).
  • Deliberate robots decision: both variants carry <meta name="robots" content="noindex"> (value from article.json), and the 404 page sends X-Robots-Tag: noindex. This is a local teaching fixture and must not enter an index if deployed by mistake.
  • No hydration is shipped: a static article with no client interactivity has nothing to re-attach.

Evidence

  • Executed: node --test fixtures/ep19-initial-html/test.mjs → # tests 11 # pass 11 # fail 0 # skipped 0 (includes a known-positive control asserting the raw CSR HTML lacks the article text, headings and links; the two DOM tests skip, not fail, if the bundled Chrome is absent).
  • Executed: node fixtures/ep19-initial-html/demo.mjs → fixtures/ep19-initial-html/evidence.json:
    • raw CSR: 200, 727 bytes, 0/6 paragraphs, 0/198 article words, 0 h1, 0 h2, 0 links, 1 script tag, "Loading article…" shell.
    • raw SSG: 200, 2520 bytes, 6/6 paragraphs, 198/198 words, 1 h1, 4 h2, 3 links, 0 script tags.
    • DOM CSR (JS on): 6/6 paragraphs, 4 h2, 3 links, data-rendered-by="client-js", requested /article.json. DOM SSG (JS on): 6/6, 4 h2, 3 links.
    • DOM CSR (JS off): 0/6 paragraphs, 0 links, shell only. DOM SSG (JS off): 6/6, 4 h2, 3 links.
    • Missing routes /csr/missing/, /ssg/missing/: 404 on both, no shell served.
    • Identical title, description and robots=noindex on both raw responses; SSG hrefs equal article.json hrefs; the CSR data file carries the same hrefs.
  • Executed: rendered-DOM capture with chrome-headless-shell (HeadlessChrome/157.0.8080.0, Remotion bundle) launched as --headless=new --no-sandbox --no-zygote --disable-gpu --disable-dev-shm-usage --no-proxy-server --user-data-dir=<tmp> --remote-debugging-port=0 about:blank, then CDP Target.createTarget → (Emulation.setScriptExecutionDisabled for JS-off) → Page.navigate → Page.loadEventFired + 1.5 s settle → Runtime.evaluate(document.documentElement.outerHTML). Plain --dump-dom hung in this container, so the DevTools protocol was used instead; the saved captures are in fixtures/ep19-initial-html/captures/dom-*.html.
  • The browser pages shown in scenes 1, 3 and 4 are illustrative recreations drawn with the kit's plain Box chrome; the numbers on them come from evidence.json. Scene 6 (crawl / render / index / rank) is labelled CONCEPTUAL ILLUSTRATION and measures nothing.

Limitations

  • A plain HTTP fetch is not a complete search-engine rendering test. A browser with JavaScript disabled is not a Googlebot simulator; Google can execute JavaScript.
  • Static generation does not guarantee indexing or rankings. Server-rendered pages can still enter a rendering stage. Nothing here measures crawling, indexing or ranking; no rendering delays, indexing timelines or Search Console results are claimed or simulated.
  • The DOM captures establish how this headless Chrome handled these pages after a fixed settle; not how every crawler handles the page.
  • Hydration was not implemented because the static page has no client interactivity; a page with interactivity would need a different comparison.
  • Measurement is string/regex counting of known synthetic content, not a DOM parser. Loopback only; no HTTPS; no real network; no caching behaviour tested.
  • Caption timing in the generated SRT is proportional to word count (heuristic alignment, not forced alignment).
